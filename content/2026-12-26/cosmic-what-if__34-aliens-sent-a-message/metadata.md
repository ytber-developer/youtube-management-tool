## Description (copy nguyên khối)
```
Forget the movies. If a radio telescope caught a real message from another civilization tonight, what would scientists actually do? Using real SETI history, from Project Ozma and the Wow! signal to a false alarm from Proxima Centauri and a practice alien message sent from Mars, we walk through the checks, the rules for announcing it, the decoding, and the hardest question of all: should we answer?
```
